# Caption rules

Adapted from rediumvex/social-media-caption-generator-claude (MIT, Roman Knox), trimmed to Titan's platforms and overridden where Titan's rules differ. **Where this file and a Titan rule conflict, the Titan rule wins.**

Write captions for four platforms on every entry: Instagram Reels, TikTok, Facebook Page, and YouTube Shorts. Add LinkedIn or Google Business Profile only if Albert asks for them. **Each platform uses a different formula** (listed below), and each one gets a one-line label so Albert can learn which formulas work.

## Titan overrides (always apply)

- Never say "link in bio," in the caption or in the video.
- The only DM or comment-keyword CTA is **DM askMaria (keyword FLOOR)**. Never write "Comment [word]" with any other word.
- Specs stay approximate ("look for AC3 or AC4," "check the manufacturer").
- Voice is friendly expert: plain, warm, confident. No hype, no fake urgency.
- Canadian spelling.
- Every platform's hashtag set includes at least one local tag: #mississauga, #torontoflooring, or #gta.

## Platform rules

### Instagram Reels
- **Length:** 80–200 characters. The first ~125 characters show before truncation, so put the hook there.
- **Structure:** Hook, then 1–2 sentences, then one CTA.
- **Hook:** Stops the scroll in 5–10 words: conflict, transformation, curiosity gap, bold statement, or a surprising fact. It should promise a *different angle* from the on-screen hook rather than repeating it.
- **SEO:** Primary keyword (e.g. "laminate flooring," "stair renovation") in the first two sentences.
- **CTA:** Aim for saves ("Save this for your reno") or sends ("Send this to someone picking floors"). Sends and saves are worth far more than likes.
- **Hashtags:** 3–5 niche tags. Never #fyp, #viral, #instagood.
- **No:** Emoji in the first line, engagement bait, generic filler.

### TikTok
- **Length:** 100–300 characters, with the hook and primary keyword in the first 80.
- **Structure:** Hook, then 1–2 short sentences, then a CTA, then a few emoji.
- **CTA:** A question works best here ("Which one did you pick?"). A "watch till the end" tease helps completion when there's a reveal.
- **Hashtags:** 3–5 max: one niche, one topic, and one local. Never #fyp, #foryou, #viral.

### Facebook Page
- **Length:** 40–80 characters for maximum reach.
- **Structure:** Ultra-short hook, then value, then a discussion question.
- **Hashtags:** 0–2.
- **Avoid trigger words:** buy now, limited time, FREE (in caps), click here, money, contest, giveaway. Safe swaps: "available now," "complimentary," "no cost," "learn more." A free quote is written as "complimentary quote" or "no-cost quote."

### YouTube Shorts
- **Title:** 40–70 characters (max 100), keyword first, and treated as a search headline. Usually this is Hook A's question. It must match the video exactly (no misleading clickbait).
- **Description:** 150–300 characters, with the hook in the first 100. Structure it as hook sentence, 1–2 value sentences, CTA (usually Follow/Subscribe), then 3–5 hashtags at the end. #shorts is optional and never the only tag.

### First comment (pin)
One engagement prompt that invites a real answer (a pick, an opinion, a "what would you do"). This goes on Instagram and TikTok.

## Formulas (use a different one per platform)

**Reach:** Myth Buster ("Myth: [belief]. Fact: [rebuttal]") · Curiosity X vs Y ("[A] vs [B]: which works for [situation]?") · Data Teaser ("[number] → [result]") · Beginner's Path ("New to [X]: [step] → [step] → [step]") · Watch Time Promise ("In 30 seconds you'll know [result]. Watch for the reveal.")

**Engagement:** Micro-Decision ("Are you [A] or [B]?") · Hot Take ("Unpopular opinion: [thesis]. Agree?") · This or That ("[A] or [B] for [situation]? Your pick?") · Rank These 3

**Sales:** Pain → Result ("Worried about [pain]? [Result] with [product/service]") · Objection Destroyer ("Think '[objection]'? Actually, [counter]") · Social Proof Lead ("'[real client quote]' Here's how:") — only use actual client words.

**Growth:** Series ("Part [N] of [series]. Follow for the rest") · Lead Magnet — only as "DM askMaria the word FLOOR for [thing]".

Label line format under each caption:
`Formula: [name] | Hook: [type] | CTA: [type] | Optimizes for: [saves / sends / comments / watch time / follows]`

## Never

- Engagement bait: "Like if you agree," "Comment YES," "Tag 3 friends," "Share before they delete this."
- More than 5 hashtags, or the identical hashtag set on every post in a batch (rotate topic tags).
- #fyp, #foryou, #viral.
- Walls of text with no line breaks.
- Urgency or financial-promise words ("last chance," "guaranteed").

## Power words

Use 2–3 per caption, from Trust (proven, tested, real results), Emotion (honest, surprising, real), Action (discover, transform), and Value (complimentary, checklist). Skip the Urgency category, since it clashes with the friendly-expert voice and Facebook's trigger-word filter.

## Signal priority

Sends/shares > saves > comments > watch time > likes. Pick each CTA for the signal that fits the content: tips and checklists aim for saves, relatable problems for sends, and This or That for comments.

## Quality check (run on every caption before writing to Notion)

- [ ] Hook sits within the first 80–125 characters
- [ ] 1–3 search keywords, used naturally
- [ ] Exactly one CTA
- [ ] 2–3 power words, no more
- [ ] 3–5 niche hashtags, including one local tag (0–2 on Facebook)
- [ ] No engagement bait, no Facebook trigger words, no "link in bio"
- [ ] Different formula on each platform
- [ ] Short lines with line breaks
